# A Birthday for Bhaursy

A standalone React + Vite birthday greeting site. It includes the original artwork, a looping animated-water overlay, and the interactive candle, wish, and share controls.

## Run locally

Requires Node.js 20.19 or newer.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To make a production build, run `npm run build`; the ready-to-host files will be in `dist/`.

The image assets are in `public/`. Keep both `bhaursy-birthday.png` and `water-motion.webp` there so the page and water animation load correctly.
